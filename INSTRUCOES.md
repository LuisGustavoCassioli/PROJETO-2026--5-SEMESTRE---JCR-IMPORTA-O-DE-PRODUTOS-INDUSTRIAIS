# 🏭 Manual de Gestão JCR Industrial (V2)

Este guia explica como operar o sistema de catálogo com a hierarquia de **Patrões (Mestres)** e **Equipe (Staff)**.

---

## 1. Como a Equipe Acessa o Sistema

Não utilizamos e-mails pessoais ou comuns. O sistema utiliza um formato de **Usuário / Código** único para cada colaborador (ex: `jose+jcr`).

* **Para entrar (Login)**: Digite o Usuário e a Senha na aba "Entrar".
* **Para criar a conta (Cadastro)**: A aba "Cadastrar" só funcionará se o Usuário tiver sido autorizado previamente por um Patrão no painel.

## 2. Níveis de Acesso (Cargos)

O sistema possui dois níveis de permissão distintos:

### 👑 Mestre (Patrões)

* **Acesso Total**: Possui controle sobre todo o sistema.
* **Gestão de Equipe**: É o único que visualiza a aba **"Gestão de Acessos"**.
* **Controle de Usuários**: Pode autorizar novos funcionários ou remover acessos existentes.

### 🛠️ Staff (Equipe/Funcionários)

* **Acesso Operacional**: Focado na manutenção do catálogo.
* **Gestão de Produtos**: Podem cadastrar, editar e excluir produtos.
* **Restrição**: Não enxergam a gestão de usuários para garantir a segurança das contas mestres.

## 3. Guia do Patrão: Autorizando a Equipe

Para dar acesso aos seus 7 colaboradores, siga este fluxo:

1. Acessem o painel administrativo.
2. Naveguem até a aba **"Gestão de Acessos"**.
3. No campo **Autorizar Usuário**, digite o nome ou código desejado (ex: `samueljcr`).
4. No seletor de cargo, escolha **"Staff (Equipe)"**.
5. Clique em **"Autorizar Acesso"**.
6. O funcionário agora pode ir na tela de login, aba **Cadastrar**, e criar sua conta usando esse código.

## 4. Gestão de Produtos

* **Cadastro**: Clique em "Novo Produto" na aba principal.
* **Galeria de Fotos**: É possível selecionar **múltiplas imagens** de uma só vez no computador.
* **Organização**: A primeira foto da galeria será a imagem principal de exibição no site.
